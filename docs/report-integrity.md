# Digital Record Integrity & Cryptographic Hashing

## 1. SHA-256 Checksum Calculation

Immediately after the binary PDF buffer is generated by `defaultPdfRenderer.renderReport()`:
```ts
const checksum = calculateReportChecksum(pdfBuffer);
```
The resulting 64-character hexadecimal SHA-256 hash is recorded in the Firestore `ReportRecord` document under `checksum`.

## 2. Live Integrity Verification (`verifyReportIntegrity`)

When `verifyReportIntegrity()` is called:
1. The stored PDF file is retrieved from Cloud Storage.
2. The SHA-256 hash of the retrieved buffer is computed live.
3. The live hash is compared against the immutable Firestore `checksum` record.
4. Returns:
   - `VALID`: Checksum matches exactly.
   - `INVALID`: Checksum mismatch (tampering detected).
   - `FILE_MISSING`: File could not be found in storage.
