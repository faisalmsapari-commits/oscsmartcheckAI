# SmartCheck Report Types & Classification

## 1. Report Types

| Report Type | Classification | Target Audience | Key Contents |
| :--- | :--- | :--- | :--- |
| `SMARTCHECK_INTERNAL` | `INTERNAL` | Planning Officers, OSC Committee, Technical Depts | Full technical results, officer assessments, machine vs officer comparison, internal issues, verified comment, audit summary. |
| `SMARTCHECK_APPLICANT` | `APPLICANT` | Applicant, Submitting Consultant (PSP) | Public summary, approved compliance results, applicant-visible issues, required actions, published verified OSC comment. All internal notes stripped. |
| `SMARTCHECK_AUDIT_PACKAGE` | `AUDIT` | Internal Auditors, State Planning Department | Complete digital provenance: rule set versions, GIS dataset versions, AI run metadata, audit event timeline, and SHA-256 checksums. |
| `MANAGEMENT_SUMMARY` | `INTERNAL` | Council Leadership, OSC Chairman | High-level executive KPI summary and category compliance statistics. |
