# Explainable Results & Evidence Chains

## 1. The 5-Stage Evidence Chain

Every SmartCheck result is backed by an end-to-end evidence chain:

```text
1. Source Project Fact / GIS Spatial Fact
   (e.g., LCP Page 42: 172 car parking bays provided)
        ↓
2. Statutory Guideline Citation
   (e.g., GPP Tempat Letak Kenderaan MPLBP Clause 4.2.1, Page 32)
        ↓
3. Mathematical Formula Trace
   (e.g., ceil(180 rooms / 4) * 1 = 45 required bays)
        ↓
4. Machine Compliance Determination
   (e.g., 172 >= 45 => COMPLIANT)
        ↓
5. Officer Review & Endorsement
   (e.g., Officer AGREE or DISAGREE with justification)
```
